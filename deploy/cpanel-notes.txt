LOCAL → DEPLOY
  npm install && npm run build
  bash scripts/deploy-ssh.sh
  cPanel → Setup Node.js App → Run NPM Install (if deps changed) → Restart

CPANEL — Setup Node.js App
  1. Software → Setup Node.js App → Create
  2. Node 18+ / Production
  3. Application root: stylearz
  4. Application URL: stylearz.com
  5. Startup file: app.js
  6. Env: NODE_ENV=production, JWT_SECRET
  7. Run NPM Install in the UI (do not npm install over SSH into app root)
  8. Start / Restart

CloudLinux: app root must not contain a real node_modules directory
(only the selector symlink).
