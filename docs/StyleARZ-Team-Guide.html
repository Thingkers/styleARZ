npm install

SSH (once per teammate)

  1. Log in to cPanel → SSH Access → Manage SSH Keys
  2. Import/generate a key → Authorize the public key
  3. Keep the private key locally (e.g. ~/.ssh/stylearz_deploy)
  4. Test:
ssh -p 21098 -i ~/.ssh/stylearz_deploy stylvrey@premium115.web-hosting.com

5. Deploy after code changes

cp credentials.example.json credentials.json
# fill credentials.json (cPanel, SSH key path, JWT_SECRET)

bash scripts/deploy-ssh.sh

Then cPanel → Setup Node.js App → Restart (and Run NPM Install only if package.json changed).
