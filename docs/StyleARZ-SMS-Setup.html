Already built in the app: POS invoice SMS + Admin → Messages (bulk festive / offer blasts). You only need to connect a live SMS gateway and save the sender number.

1. Your checklist

  1. Pick an SMS provider that can send to Bangladesh numbers (01XXXXXXXXX).
  2. Add provider credentials in cPanel → Setup Node.js App → Environment variables (never commit secrets to git).
  3. In the site: Admin → Settings → save the SMS sender mobile (balance account).
  4. Restart the Node.js application in cPanel.
  5. Test: one POS invoice SMS, then Admin → Messages with a manual list of 1–2 phones before any full blast.

2. Where to click in Admin

Screen What to do
Admin → Settings Save SMS sender mobile (01XXXXXXXXX)
Admin → Messages Preview + send bulk SMS (inauguration guests / POS phones / manual list)
POS → invoice Send one receipt SMS to a customer

3. Environment variables (cPanel)

Option A — Log only (safe until gateway is ready)

SMS_PROVIDER=log

Writes messages to the server log. No real SMS is sent. Use this for dry-runs.

Option B — HTTP SMS gateway (typical BD aggregators)

SMS_PROVIDER=http
SMS_HTTP_URL=https://YOUR-GATEWAY/api/send
SMS_HTTP_METHOD=POST
SMS_HTTP_TOKEN=your_api_token_if_needed
SMS_HTTP_SENDER=01XXXXXXXXX

The app POSTs JSON similar to:

{
  "to": "017xxxxxxxx",
  "phone": "017xxxxxxxx",
  "message": "...",
  "text": "...",
  "from": "01XXXXXXXXX",
  "sender": "01XXXXXXXXX"
}

If the provider uses different field names, share their API docs with Thingkers so we can map them.

Option C — Twilio

SMS_PROVIDER=twilio
TWILIO_ACCOUNT_SID=ACxxxxxxxx
TWILIO_AUTH_TOKEN=xxxxxxxx
TWILIO_FROM=+8801XXXXXXXXX

Also save the same sender number in Admin → Settings.

4. Bulk SMS audiences

  • Inauguration guests — phones that claimed a Grand Opening slot
  • POS customers — unique phones from completed POS sales
  • Manual list — paste numbers for a one-off festive blast
Before a full send: always use Preview, then test a manual list of 1–2 phones. Real SMS costs money. Keep festive copy under ~480 characters.

5. Done when…

  • Admin → Settings shows your sender number
  • Gateway is http or twilio (not stuck on log for production)
  • A test invoice SMS arrives on a real phone
  • A 1–2 number bulk send from Messages arrives
